The name of this app is Econo Camera. This app will have access to the camera. The reason for this name is that it will have the following camera resolutions:
- 60p
- 120p
- 240p
- 480p
- 720p
The purpose of this is so that the user can make video recordings on his phone without wasting valuable space on his phone. In addition, there will be an mp3, and mp4 converter included, along with audio to text.  The same thing will apply with using the camera. It will also include a feature where the user can turn his pictures into cartoon animations of his choosing.  The pano option will also be available with the same animation option.
